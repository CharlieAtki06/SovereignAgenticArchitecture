# Codebase graphs

Interactive viewers generated by [graphify](https://github.com/Graphify-Labs/graphify). Open in a browser — no install needed.

| Zone | Viewer | What it maps |
|---|---|---|
| Zone 1 — Edge Runtime | [zone1/graph.html](zone1/graph.html) | `runtime/src/zone1/` — LangGraph orchestrator, MCP client, capability access, model execution |
| Zone 2 — Governed Mediation | [zone2/graph.html](zone2/graph.html) | `src/zone2/` — 8 bounded contexts, policy engine, connectors, audit, contracts |

These files are committed so teammates can explore the graph without installing graphify.

## Regenerating

```bash
# From the root envelope repo:
./scripts/generate-graphs.sh
```

Prerequisites: `uv tool install graphifyy && graphify install`

The AI-context files (`graph.json`, `GRAPH_REPORT.md`) live in each zone's repo and are gitignored. To regenerate them, open a Claude Code session in the relevant zone and run `/graphify .`.
