# Codebase graphs

Interactive viewers generated by [Graphify](https://github.com/Graphify-Labs/graphify).
They are code evidence, not the public system map or architecture authority.

| Zone | Viewer | What it maps |
|---|---|---|
| Edge — Zone 1 | [Open viewer](/code-graphs/zone1) | Edge Runtime, LangGraph orchestration, MCP client, capability access, model execution |
| Governance Gateway — Zone 2 | [Open viewer](/code-graphs/zone2) | Bounded contexts, policy engine, connectors, audit, contracts |

These files are committed so viewers can explore the graph without installing
Graphify. Their source revisions are recorded in `manifest.json` and must match
the architecture evidence lock.

## Regenerating

```bash
# From the root envelope repo:
./scripts/generate-graphs.sh
```

Prerequisites: `uv tool install graphifyy && graphify install`

The AI-context files (`graph.json`, `GRAPH_REPORT.md`) live in each zone's repo
and are gitignored. Run `/graphify .` in the relevant zone to regenerate them.
